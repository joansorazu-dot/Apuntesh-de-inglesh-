# Apuntes de inglés

Página de estudio con flashcards interactivas, collocations y ejercicios tipo C1.

## Abrir la página

https://joansorazu-dot.github.io/Apuntesh-de-inglesh-/

## Instalar en el móvil

Abre el enlace en el navegador del móvil y selecciona **Añadir a pantalla de inicio** o **Instalar aplicación** desde el menú.

## Actualizar los apuntes

La página se publica desde la rama `main` mediante GitHub Actions. Cada actualización subida a esa rama inicia un nuevo despliegue.
